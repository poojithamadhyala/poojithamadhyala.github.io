Jira Ticket Tracker Dashboard

A Jira Cloud gadget that gives your team a real-time visual snapshot of every open ticket — who owns it, how urgent it is, and what's slipping past SLA deadlines.

SLA / Aging — filterable table, color-coded by ticket age

✨ Three Tabs, Three Questions Answered

📊

Overview

"How are we doing?" — Total open, status distribution, priority breakdown, SLA health at a glance.

👥

By Assignee

"Who's overloaded?" — Expandable cards per person showing ticket count and priority spread.

⏰

SLA / Aging

"What's slipping?" — Every ticket color-coded by age. Filter by On Track, At Risk, or Overdue.

🚦 SLA Thresholds

On Track

< 48 hours open

At Risk

48 – 96 hours open

Overdue

> 96 hours open

🏗️ Architecture

Jira Cloud (iframe)
  └── React Dashboard (Vite + Recharts)
        └── FastAPI Backend (JWT auth, JQL queries)
              └── Jira Cloud REST API v3

Backend authenticates with Jira → runs JQL → aggregates by status, assignee, SLA → returns one JSON payload → frontend renders interactive charts and tables inside a Jira dashboard widget.
